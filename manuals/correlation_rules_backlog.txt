# OpenSIEM Correlation Engine v2 — Future Rules Backlog

Rules are grouped by the v2 feature they exploit.
Existing rules (10–41) already benefit from v2 time-window and ordering enforcement.
These new rules specifically use entity_field='user', threshold_count, or entity_field='global'.

---

## USER-BASED GROUPING (entity_field = 'user')

These rules detect attacks that span multiple source IPs but target the same account.

| ID  | Rule Name                                      | Steps                                             | Window  | Severity |
|-----|------------------------------------------------|---------------------------------------------------|---------|----------|
| 70  | Credential Reuse Across Servers                | Auth failure on host A → success on host B        | 10 min  | High     |
| 71  | Account Enumeration to Takeover                | Multiple invalid user attempts → valid user login | 5 min   | High     |
| 72  | Privilege Escalation after Lateral Movement    | Remote login → sudo/su success (same user)        | 15 min  | Critical |
| 73  | Off-hours Login After Daytime Failure          | Failed login during business hours → success at night | 8 hr | High  |
| 74  | VPN Login Followed by Internal Recon           | VPN authentication → internal host sweep          | 30 min  | High     |
| 75  | Database Login After Web App Auth Failure      | Web app auth failure → direct DB login same user  | 10 min  | Critical |
| 76  | Windows Admin Login After Linux Failure        | Linux SSH failure → Windows RDP success same user | 15 min  | Critical |
| 77  | Service Account Used Interactively             | Service account login_failed → interactive logon  | 5 min   | High     |

| 92  | Distributed Web Application Attack             | SQL injection attempts from multiple IPs           | 5 min  | High     |

| 94  | DDoS Pre-cursor Detection                      | N connection floods from different IPs             | 60s    | Critical |
| 95  | Multi-Source Log Tampering                     | Log clear / rotate events from multiple hosts      | 5 min  | Critical |
